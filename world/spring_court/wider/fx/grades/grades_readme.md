# Spring Court grade presets

Generated by `world/spring_court/wider/fx/tools/build_court_fx.gd`; edit the table there, not the files.

GradePreset resources (`world/shared/grades/grade_preset.gd`) for the wider-court regions.
GradeDirector loads presets by id from `world/shared/grades/<id>.tres`, so the world lane copies
each file there unchanged (the id equals the file name). Regions then add a RegionGrade node:

```
RegionGrade  grade = &"grade_rosewild"  bounds = Rect2(-600, -800, 1100, 300)  blend_seconds = 4.0
```

`lut` is an embedded GradientTexture1D (dark, mid, light): a gentle pastel colour-correction ramp,
no image files. Recommended GradeDirector Environment for all of these: tonemap AgX, glow on
(soft-light blend, hdr threshold ~0.9), fog + volumetric fog on, SDFGI on, SSAO on at intensity ~0.8.
grade_blight is horror: keep it grey and silent, never tone it down.
