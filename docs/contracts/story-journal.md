# Story journal contract (L54): Feyre's sketchbook

The one place the game states where Feyre is in the story and what she's
after (R2 as amended for L54). Opt-in only: never on the HUD, the map, the
minimap or in the world.

## Opening it
- Key **L** (`journal_open`, added at runtime by `StoryJournal.ensure_action()`; no project.godot change).
- Pause menu: **Journal** button (ui/settings_panel.gd).
- Satchel: **Sketchbook** flap (L50-3).
- Any lane: `StoryJournal.open_from(get_tree())` (adds one to the root if the scene has none).
- Pauses the tree while open, like the satchel. L / Esc / ui_cancel close it.

## Data
- `data/journal/story_journal.tres` (JournalBook) is generated by
  `tools/journal/build_journal.py`; edit the script, never the .tres.
- One `JournalChapter` per phase id in `data/phases/spring_court_phases.tres`;
  every exit-condition flag is some `JournalEntry.done_flag` (tested).
- `JournalEntry`: `done_flag`, `require_flags`, `fail_flags`, `after`
  ("what I'm after"), `hints` (1–3, gentle to plain; only the last may name a
  key), `memory` (past tense, shown once done), `sketch` (JournalSketch.MOTIFS),
  `guide_thread` (borrows flags and lines from data/guide/act1_guide.tres),
  `canon` (A/V/X).
- Current step = the furthest ready, not-done step of the current phase's
  chapter in story order. Later steps are never drawn.

## Hints (HintLadder)
- Hint k unlocks at `STUCK[k]` s of unpaused play on the step (60/180/360) or
  `ATTEMPTS[k]` failed tries (1/2/4), whichever comes first.
- A failed try: a `fail_flags` flag rising, or the same scene space starting
  again while the step is open (`EventBus.scene_space_started`).
- Unlocked hints show only when the player asks (E / Enter / pad A / "Think on it").

## Reads, never writes
WorldState.has_flag, PhaseManager.current_phase, EventBus.flag_changed and
scene_space_started. It sets no flags and emits no story signals.

## Look
SatchelTheme.theme() only (L13 theme + L50 crafted layer): SatchelDetail paper
pages, SatchelKey leather cover and key caps, SatchelTab button, Satchel*
label variations, Satchel colours for the ink sketches and spiral binding.
